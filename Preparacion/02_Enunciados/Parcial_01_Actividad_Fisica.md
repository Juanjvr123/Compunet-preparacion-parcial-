# Parcial 01 - Aplicacion de actividad fisica universitaria

## Contexto

La universidad necesita una SPA para que estudiantes y colaboradores registren sus rutinas de actividad fisica, consulten su progreso y reciban apoyo de entrenadores.

## Requerimientos funcionales

1. Los usuarios deben iniciar sesion con usuario y contrasena.
2. El token JWT debe guardarse y enviarse en cada peticion protegida.
3. Deben existir roles `USER`, `COACH` y `ADMIN`.
4. El usuario puede ver sus rutinas asignadas.
5. El usuario puede registrar progreso semanal.
6. El usuario puede consultar estadisticas basicas.
7. El usuario puede descargar un reporte PDF.
8. El entrenador puede ver estudiantes asignados.
9. El entrenador puede recomendar rutinas.
10. El administrador puede ver un panel de gestion.

## Requerimientos tecnicos

- React con Vite.
- Material UI.
- React Router DOM.
- Axios.
- JWT Decode.
- ESLint.
- Componentes reutilizables.
- Hooks personalizados.

## Entregables

- Codigo fuente.
- README con comandos.
- Sustentacion presencial.
- Evidencia de build.

## Criterios de evaluacion

- Componentes y paginas: 50%.
- Calidad de codigo: 10%.
- Servicios y autenticacion: 30%.
- Diseno: 10%.
